## 1. Relabeling — this is the refined position of §4's hook, not adjacent work

`WO009_PRESENTATION_LAYER_CONTRIBUTION.md` §4 named a "Dual-purpose hook for the upcoming EDU/DACUM AC" — at the time, a thin, two-value sketch: `glass-swirl.riv`/`VesselData` renders either **Product** mode (commerce lookup table) or **Induction** mode (pedagogical lookup table, "DACUM task-analysis walkthrough"). That was written before this document existed in this engagement's context.

**The stress test is that hook, refined** — not a separate artifact, not competing content. What was a single undifferentiated "induction mode" is actually four distinct competency frames (vocational, cultural, educational, avocational), each with its own validation rules, its own stakeholders, and in the cultural frame's case, its own sovereignty and revenue-split logic entirely outside what a two-value mode flag can express. The stress test is what §4's "pedagogical cues per competency stage" cashes out to when actually specified against a real case (Martha).

This reframing will matter directly to the fit question already open on COR-43/FRM-48 — namely, how the stress test's four frames compare to PART-98's single D3 duty FRM-48 is already pointed at. Held for next turn's full synthesis, per your instruction — noted here only so the relabeling itself doesn't get lost before then.
